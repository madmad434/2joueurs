Jouer à deux

Les six jeux partagent exactement la même mise en relation : ce qui est appris sur l'un vaut pour les cinq autres.

En ligne, en trois gestes rien à installer

  • 1️⃣ Ouvrir 🌐 Connexion, puis « Créer une partie » Le jeu affiche un code de cinq caractères et un lien d'invitation.
  • 2️⃣ Envoyer le code (ou le lien) à l'autre joueur Par message, courriel, oralement : cinq caractères suffisent.
  • 3️⃣ L'autre choisit « Rejoindre une partie » et saisit le code La liaison est directe d'un navigateur à l'autre. L'hôte lance ensuite les manches.

Sur un seul écran sans réseau

Le bouton « Jouer en local » de la même fenêtre fait tout tenir sur un poste : les deux joueurs se passent la souris pour le Morpion, les Dames et l'Awalé, et jouent chacun leur tour, sur la même graine, pour Comète et Météorite. Pong Néon se joue à deux en même temps, W / S d'un côté et ↑ / ↓ de l'autre.

Raccourcis : tapez 1 à 6 pour lancer un jeu directement. Le mode en ligne demande une adresse https://… ; en double-cliquant sur le fichier, seul le mode local est garanti. Le bouton ❓ Aide, en haut à droite, détaille tout cela.

Aide du menu

À quoi sert cette page

C'est le menu de la collection. Il ne contient aucun jeu : il ne fait que les lancer. Chaque jeu est un fichier autonome, que l'on peut aussi ouvrir directement, mettre en favori ou placer en raccourci sur le bureau. Chaque jeu comporte un bouton ✕ Quitter qui ramène ici.

Lancer un jeu

  • Cliquez sur une tuile, ou tapez son numéro au clavier, de 1 à 6.
  • Le nom du fichier lancé est écrit sous chaque description.

La case « Ouvrir dans un nouvel onglet »

Elle ne change rien à la façon de jouer : elle décide seulement si le jeu remplace le menu dans le même onglet, ou s'ouvre à côté. Le réglage est retenu d'une visite à l'autre.

Jouer seul

Comète et Météorite proposent un choix 1 joueur — solo dans leur bandeau : ni adversaire ni connexion, le meilleur score est conservé sur l'appareil. Ces deux jeux laissent aussi régler la vitesse et les touches ; en duel, le réglage de l'hôte s'applique aux deux joueurs pour que le défi reste identique.

Jouer à deux

Dans chaque jeu, le bouton 🌐 Connexion ouvre la même fenêtre, avec trois possibilités.

ChoixCe qui se passe
Créer une partie Le jeu affiche un code de cinq caractères et un lien d'invitation. Vous êtes l'hôte : c'est vous qui lancez les manches et, dans les jeux d'action, qui tirez la graine du parcours.
Rejoindre une partie Saisissez le code reçu, ou ouvrez directement le lien d'invitation : le code est alors déjà rempli.
Jouer en local Aucun réseau : les deux joueurs se partagent l'écran. Pour Comète et Météorite, chacun joue son tour sur la même graine, donc sur le même parcours ; ces deux jeux proposent aussi un vrai mode solo.

La liaison est directe d'un navigateur à l'autre (WebRTC, via la bibliothèque PeerJS) : aucune donnée de partie ne passe par un serveur, seul un annuaire public sert à la mise en relation.

Le mode en ligne demande une adresse https://… — GitHub Pages, Netlify, Vercel, ou un simple serveur local. Ouvert par double-clic depuis le disque (file://), certains navigateurs bloquent WebRTC : le mode local, lui, fonctionne toujours.

Pendant la partie

  • Le bandeau bleu sous les boutons indique l'état de la liaison, le code de la salle et la latence mesurée.
  • La barre de statistiques rappelle en permanence à qui c'est le tour, le score et l'avancement de la manche.
  • Le panneau de gauche réunit les deux joueurs, une discussion avec réactions rapides, et l'historique des coups ou des scores. Il disparaît sur les écrans étroits.
  • Chaque jeu a son propre bouton ❓ Aide, avec ses règles détaillées.
🔧 Partie technique — publication et fonctionnement en réseau

Cette section ne sert que si vous publiez la collection ou si vous voulez comprendre ce qui circule sur le réseau. Elle n'est pas nécessaire pour jouer.

Publier la collection

Envoyez le contenu de ce dossier — et non le dossier lui-même — sur un dépôt GitHub public, de sorte que index.html se retrouve à la racine, à côté des six fichiers de jeu. Puis, dans le dépôt : Settings → Pages, source Deploy from a branch, branche main, dossier / (root). Tous les chemins sont relatifs : l'adresse du dépôt n'a aucune importance.

Essayer en local comme si c'était en ligne

Placez-vous dans ce dossier et lancez :

python3 -m http.server 8000

puis ouvrez localhost:8000. Attention : http:// sur localhost suffit pour tester à deux onglets sur la même machine, mais deux machines différentes demandent une vraie adresse https://….

Deux façons de synchroniser deux joueurs

FamilleCe qui circule
Morpion, Dames, Awalé Le coup joué, puis un état complet renvoyé par l'hôte. Les deux postes appliquent la même fonction de règles : l'état reste identique des deux côtés.
Comète, Météorite Une graine au départ, un score à l'arrivée, et rien entre les deux. Le parcours est reconstruit à l'identique de chaque côté par un générateur déterministe, et la simulation tourne à pas fixe en unités relatives : un téléphone et un PC obtiennent le même parcours.
Pong Néon Du temps réel : l'invité envoie la hauteur de sa raquette environ trente fois par seconde, l'hôte — seul arbitre — simule la balle et diffuse sa position. L'invité n'effectue aucune simulation : aucune divergence n'est possible.

Si la connexion échoue

  • Vérifiez que les deux joueurs ouvrent bien la même page en https://….
  • Un réseau d'entreprise ou un VPN strict peut bloquer WebRTC : essayez en partage de connexion mobile.
  • Le code est valable tant que l'hôte garde sa page ouverte ; s'il la recharge, un nouveau code est tiré.
