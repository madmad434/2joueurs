🎮 Comment jouer — Awalé

  1. But du jeu : capturer plus de graines que l'adversaire. 48 graines au départ, 4 par case ; le premier à 25 a gagné d'avance.
  2. Semer : cliquez sur une de vos six cases : toutes ses graines sont réparties une par une, dans le sens antihoraire, dans les cases suivantes. Avec 12 graines ou plus, la case de départ est sautée.
  3. Capturer : si la dernière graine tombe dans une case adverse qui atteint 2 ou 3 graines, cette case est récoltée. La récolte se poursuit en chaîne vers la case précédente tant qu'elle est adverse et contient 2 ou 3 graines.
  4. Règle de la famine : il est interdit de jouer un coup qui laisserait l'adversaire sans aucune graine si un autre coup le nourrit. Les coups interdits ne sont tout simplement pas proposés.
  5. Si aucun coup ne nourrit l'adversaire, le joueur récolte toutes les graines restantes et la partie s'arrête. Si un camp est vide, l'autre joueur récolte le plateau.
  6. Fin : le grenier le plus plein gagne ; 24 — 24 est un match nul. Une position bloquée (60 coups sans capture) est partagée : chacun récolte son camp.
  7. En ligne : l'un crée la partie et envoie le code à 5 caractères (ou le lien) ; l'autre le saisit. Chaque coup est recalculé à l'identique des deux côtés, et l'hôte renvoie un état complet après chaque coup.
  8. Mode local : les deux joueurs partagent le même écran, sans aucune connexion.

Boutons communs du bandeau : 📜 Historique ouvre le relevé de la partie, que l'on peut imprimer ; il est aussi accessible depuis la fenêtre de fin de manche. 🔊 Son coupe ou rétablit les effets sonores, et le choix est mémorisé. ⟲ Réinitialiser arrête la partie en cours sans quitter la page. ✕ Quitter revient au menu.

🌐 Pour utiliser le mode en ligne, le fichier doit être servi en HTTPS (GitHub Pages, Netlify, Vercel…) — WebRTC est bloqué sur un simple fichier local file:// dans certains navigateurs.
